ℹ️ About AgriClimate AI

AgriClimate AI is a climate-smart farming assistant designed to help farmers make better crop decisions using soil and environmental information.

The system uses a Machine Learning model to recommend a suitable crop based on nitrogen, phosphorus, potassium, temperature, humidity, soil pH and rainfall.

It also provides irrigation advice, climate-risk indication, disease-risk indication and suggested farming actions.
