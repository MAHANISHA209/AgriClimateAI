# 🌱 AgriClimate AI

## AI-Based Climate-Smart Farming Assistant

AgriClimate AI is a web-based AI/ML application designed to support farmers with climate-aware agricultural decisions.

The system analyzes soil and environmental parameters and recommends a suitable crop using a Machine Learning model. It also provides weather information, irrigation guidance, climate-risk indication, environmental disease-risk indication, and suggested farming actions.

## DEPLOY LINK
https://agriclimateai.onrender.com

## 🎯 Problem Statement

Agriculture is increasingly affected by:

- Unpredictable temperature changes
- Changing rainfall patterns
- Water scarcity
- Inefficient irrigation
- Difficulty in selecting suitable crops
- Environmental conditions that may increase crop disease risk

Farmers need simple and accessible data-driven guidance to make better climate-aware farming decisions.

---

## 💡 Proposed Solution

AgriClimate AI combines Machine Learning and weather information to provide simple agricultural recommendations.

### The system provides:

- 🌾 AI-based crop recommendation
- 🌦️ Current weather information
- 💧 Irrigation guidance
- 🌡️ Climate-risk indication
- 🦠 Environmental disease-risk indicator
- 🌱 Suggested farming action
- 📌 Crop-specific farming information
